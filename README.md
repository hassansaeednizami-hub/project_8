# 🎬 Netflix Clone

A modern and responsive **Netflix landing page clone** built using **HTML5 and CSS3**. This project recreates the look and feel of the official Netflix homepage with a clean layout, smooth design, and responsive user interface.

---

# ✨ Features

* 🎥 Modern Netflix-inspired landing page
* 📱 Responsive design for different screen sizes
* 🎨 Beautiful hero section with background image
* 🧭 Navigation bar with Netflix branding
* 📧 Email subscription section
* 🎞️ Trending Movies section
* 📺 Multiple feature sections
* ❓ FAQ accordion design
* 🚀 Smooth hover effects and transitions
* 💻 Clean and well-structured code

---
